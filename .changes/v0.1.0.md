## v0.1.0 - 2026-11-15
### Added
* listen, which answers over HTTP and costs nothing between visits, and peer, which says who is at the other end of a connection: both moved in whole, with no change in behaviour
* caller gains Front, the two headers a front writes and the program behind it reads, with a writer that deletes every header carrying the front's prefix first and always, a refused write among them, and writes nobody for the zero Visitor, and a reader that refuses either header twice, an empty who, a who or may word that is not UTF-8 or holds a control, format or separator character, and any other header carrying the front's prefix; RemoteUser and RemoteHeaders, a login proxy's Remote-User and Remote-Groups, believed only on the proxy's own listener and refused when written twice or when a user or group is not UTF-8 or holds such a character; Roles, the roles a capability's grants name, each once and in order; SameLogin and FoldLogin; the permission name grammar IsName, IsSegment, CheckPattern and Expand, with the fuzz target FuzzExpand; and the tailnet kit: CheckVersion (Tailscale 1.94 or later, the first whose serve takes a unix: target), TailscaledUID (ErrNoOwner, wrapping errors.ErrUnsupported, off the unix systems) and Serve's tailscale serve arguments and quoted command line.
* wire, length-prefixed JSON frames under a cap (64 KiB unless the caller gives another) and a strict envelope with a typed error from a closed list, and registry, which opens an implementation by its kind and tells a kind this machine does not serve from one nobody registered: both import the standard library alone
* peer on Windows: ListenPipe makes a named pipe that SYSTEM, the pipe's owner (the default owner of the listener's token) and the SIDs it is given alone may open, its access list set as it is made: each SID may read and write and may not make a server end (no FILE_CREATE_PIPE_INSTANCE), which the pipe's owner alone may. It refuses no SID, a SID not written as Windows writes it back, and the null SID, Everyone, ANONYMOUS LOGON, Authenticated Users, BUILTIN\Users, INTERACTIVE and LOCAL; DialPipe dials at the identification level asking for a listed SID's rights alone; both refuse a name that is not \\.\pipe\ and then a name, or whose last part ends in a dot or a space, which Win32 drops, and are ErrCannotSay off Windows. PeerOf on the listener's side is the client's SID, read by impersonating it on a locked thread of its own, panicking if the thread cannot be made itself again, and refuses by name an anonymous dial and a client whose token holds its user for deny alone; on the dialling side it is the pipe's owner, the account whichever of its tokens made the pipe, one holding the user for deny alone included. Principals takes a SID
### Changed
* TailscaleServe, ServeHeaders, Served and the Header constants move from peer to the new package caller, which imports the standard library alone; peer keeps no alias. The capabilities document is read by encoding/json/v2: a name written twice in any object, escaped or not, a null document, and any capability whose values are not a list or null are refused, and Served.Values is now []jsontext.Value, empty when the values are null. A capabilities header longer than MaxCaps, 64 KiB as it came, is refused with ErrTooLong.
* peer: PeerOf gives the peer of a unix socket as a principal (Unix), with the process where the kernel says it (PIDKnown), on Linux, macOS and FreeBSD, and is ErrCannotSay for any other connection; Listener gates by Principals and tells refused the principal. UID, PeerUID and PeerPID are gone, with no alias
* listen: Listen holds <path>.lock and decides by five rules (a held lock or a socket that answers is ErrHeld, anything not a socket is left, a refused socket with the lock ours is replaced, any other failure is refused; a full queue, as Linux says it, is ErrHeld), refuses an empty address with ErrNoAddress and a lock file name that is a link or not a plain file with ErrLockNotAFile, makes a relative path absolute, removes on Close only the socket it bound, binds through go-connections with the mode and group set before it listens, and works on Windows; Activated keeps the names systemd passes and is ErrNotActivated, which wraps errors.ErrUnsupported, off Linux; Listener is a pointer with Name and Local; CacheControl, Hashed, Guard, GuardFunc, Accepted and Listener.Unix are removed with no alias
### Security
* caller: TailscaleServe refuses a login that is not UTF-8 or holds a control, format, line or paragraph separator character, as Front and RemoteUser refuse a name; CheckVersion's floor is Tailscale 1.94, and below 1.92 its error says a caller can write its own grants, which a serve that old passes on
* caller: Front, RemoteUser and TailscaleServe also refuse a name holding a default ignorable code point (U+034F, the Hangul fillers) or a variation selector, each of which prints as nothing; CheckVersion's doc says the version is tailscaled's, the lower of the two when a program has both, and the README names the login with a space or tab at either end, which net/http reads as the login without it

The non-test Go lines outside internal/: 2721.
