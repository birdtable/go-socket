## v0.4.0 - 2026-11-19

v0.4.0 adds one call to `listen` and changes nothing a program already uses. Upgrading from v0.3 needs no change.

### Added

**listen**
* `Local(folder, name)` gives the address `Listen` takes on this system for a socket the program names. That address is also what a client is told: `SSH_AUTH_SOCK`, for example.
  * On macOS, Linux and the BSDs, it's the name in the folder, made absolute. If a socket's address can't hold that path, `Local` refuses it with the error `Listen` would give, and doesn't move it to another folder.
  * On Windows, it's `\\.\pipe\<name>-<h>`, where `<h>` is 16 hex digits of the SHA-256 of the folder's absolute path. So two folders never give the same pipe, and the same folder and name always give the same one.
  * A name that is not one plain name is refused before any address is formed: empty, `.`, `..`, a slash or backslash, a NUL, or, on Windows, a name a pipe can't end in, such as one ending in a dot or a space.
  * `Local` makes nothing, and looks at the folder only to make it absolute.

Nothing is removed or moved: `API.txt` gains `listen.Local` alone.
